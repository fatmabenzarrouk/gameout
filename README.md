# GAMEOUT — The Gaming Social Network

**Connect. Compete. Share. Level Up.**

GAMEOUT is a modern gaming social network designed to bring gamers together in one platform. Discover gaming communities, connect with other players, share experiences, and build your gaming identity.

---

## About GAMEOUT

GAMEOUT aims to create a connected gaming ecosystem where players can interact beyond individual games.

Whether you're a casual gamer, competitive player, content creator, or gaming enthusiast, GAMEOUT provides a space to connect, communicate, and grow.

##  Key Features

-  **User Profiles** — Create and customize your gaming identity.
-  **Social Feed** — Share gaming moments, updates, and experiences.
-  **Gaming Community** — Discover and connect with other gamers.
-  **Gamification** — Make engagement more rewarding through gaming-inspired experiences.
-  **Social Interaction** — Engage with other players and their content.
-  **Gaming Experience** — Build your presence and participate in the gaming ecosystem.

*Note: Features are subject to implementation and availability in the current release.*

## 🛠️ Technology Stack

GAMEOUT is built using modern web technologies.

- **Frontend:** Vite
- **Backend / Database:** Firebase Firestore
- **Deployment:** Google Cloud Run
- **Version Control:** Git & GitHub

##  Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/fatmabenzarrouk/gameout.git
```

2. Navigate to the project:

```bash
cd gameout
```

3. Install dependencies:

```bash
npm install
```

4. Configure the required environment variables.

5. Start the development server:

```bash
npm run dev
```

## 🔐 Security

- Never commit API keys, private credentials, or service account
